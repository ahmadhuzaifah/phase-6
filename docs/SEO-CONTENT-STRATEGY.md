# SEO Content Strategy

## Programmatic page rules

Create a page only when it answers a distinct search intent and has real supporting data. Priority clusters are:

- `5 Marla plots in DHA Phase 6 Lahore`
- `10 Marla houses in DHA Phase 6 Lahore`
- `Best blocks in DHA Phase 6 Lahore`
- `Affordable plots in DHA Phase 6 Lahore`
- `Investment opportunities in DHA Phase 6 Lahore`

Each page must include unique copy, a dated data snapshot, links to relevant sources, map or sector context, a verification disclaimer, and a canonical URL. Do not create size and sector combinations without source-referenced records or repeat the same paragraph with keywords swapped.

## Editorial cadence

- Weekly: verify prices, availability, and development updates.
- Twice monthly: publish one buying, map, legal, or investment guide.
- Monthly: refresh internal links from the homepage, prices, blocks, and property directory.

## Internal-link pattern

Property pages should link to their block, prices, map, and relevant guide. Block pages should link to matching properties, nearby places, and location pages. Articles should link to the exact directory or guide that supports the advice.

## Image SEO

Use descriptive filenames such as `5-marla-plot-block-a-lahore.webp`, specific alt text, explicit dimensions, and lazy loading below the fold. Publish only clean, permissioned images processed through the existing compliance and watermark workflow.
