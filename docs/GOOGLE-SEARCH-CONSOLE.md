# Google Search Console

1. Add the final production domain as a Domain property.
2. Complete the DNS TXT verification.
3. Set `PUBLIC_GSC_VERIFICATION` only if the HTML-tag method is used.
4. Submit `https://YOUR-DOMAIN/sitemap-index.xml`.
5. Inspect the home page, sector hub, property hub, map guide and price guide.
6. Monitor indexing, Core Web Vitals, manual actions and structured-data reports.

Search ranking cannot be guaranteed. Build authority with accurate original content, reliable source attribution, technically sound pages and legitimate local references.
