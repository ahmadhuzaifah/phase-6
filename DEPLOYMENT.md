# Deployment

## Local verification

```powershell
npm install
npm run check
npm run build
npm run seo:audit
```

## GitHub and Vercel

The production repository is `https://github.com/ahmadhuzaifah/phase-6`.

1. Import the repository into Vercel.
2. Use the Astro framework preset and the default build command.
3. Set `PUBLIC_SITE_URL` to the final HTTPS origin.
4. Optionally set `PUBLIC_CONTACT_PHONE`, `PUBLIC_WHATSAPP_NUMBER`, `PUBLIC_CONTACT_EMAIL`, `PUBLIC_GA_ID`, and `PUBLIC_GSC_VERIFICATION`.
5. Add the final domain in Vercel and update DNS.
6. Submit `/sitemap-index.xml` in Google Search Console.

Do not publish third-party property photographs unless written reuse rights are documented. Never remove or replace another publisher's watermark.
